# AurionClient

Welcome to the official repository for the **AurionClient** modpack—a modpack created for anarchy servers like 2b2t and 6b6t!

## General Information

* **Modpack Name:** AurionClient
* **Modpack Version:** 1.0.0
* **Minecraft Version:** 1.21.11
* **Mod Loader:** Fabric Loader (version `0.19.3`)

## Installation

1. Download the `.mrpack` file from the [Releases](../../releases) section of this GitHub repository.
2. Open your Modrinth-compatible launcher (e.g., Modrinth App, Prism Launcher).
3. Import the `.mrpack` file.
4. Launch the game and enjoy **AurionClient**!
